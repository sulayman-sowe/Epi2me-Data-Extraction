### Epi2me-Data-Extraction

An automated, reproducible R pipeline designed to parse, clean, and structure high-throughput long-read sequencing metadata generated by Oxford Nanopore Technologies (ONT) EPI2ME workflows. 

### 🧬 Biological & Technical Context

The EPI2ME platform provides fast, cloud- or local-based analysis of Oxford Nanopore sequencing data. However, the raw analytical output files are often deeply nested, unstructured, or dense. This pipeline acts as a bridge, extracting vital diagnostic and genomic parameters (such as read lengths, quality scores, annotations, sequence types, AMR determinants) into tidy, downstream-ready data frames. 

### 🛠️ Tech Stack & Dependencies

* **Language:** R (v4.0 or higher)
* **Libraries:** tidyverse (dplyr, tidyr, readr, ggplot2), data.table (for memory-efficient loading of large sequencing runs)

bash

### Execution Example

Ensure your input file paths are configured correctly inside the R script or call it directly from your terminal: 

bash
